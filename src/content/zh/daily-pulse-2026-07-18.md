### 2. 🧹 Oomwoo：开源扫地机器人项目 GitHub 获 4390★，清洁机器人创客化启动

**一句话总结**：_一个名为 Oomwoo 的全开源扫地机器人项目在 GitHub 获得 4390 星——从 BOM 清单到固件全部开放，证明开源机器人运动正在从人形延伸到清洁品类。_

> 💡 **为什么重要**：过去一年，开源人形机器人项目（OpenArm、Roboto_origin）获得了大量关注。但 **Oomwoo 的出现说明开源硬件运动正在向"家用机器人"品类延伸**。扫地机器人是全球出货量最大的机器人品类——如果这个品类也进入"GitHub 下载→3D 打印→自行组装"的模式，影响将远超人形机器人创客圈。

Oomwoo 被描述为 "Open-source vacuum robot cleaner"——但目前的信息显示它更像一个开放的机器人清洁平台，而非简单的扫地机 DIY 项目。其技术架构值得关注：

- **完全开放的硬件设计**：包含 PCB 设计文件、3D 打印外壳模型、传感器布局图
- **可定制的控制固件**：基于流行的嵌入式平台，支持 SLAM 导航算法替换
- **模块化清洁单元**：吸尘模块、拖地模块可独立升级

对比扫地机器人行业正在进行的"基础设施化"趋势（自动上下水、多楼层地图），Oomwoo 的开源路线走的是完全不同的方向——**不是让扫地机更像家电，而是让它更像开发平台**。

### 3. 🏗️ 机器人开源基础设施迎来集中爆发：Genesis、Copper RS、OpenTau 引领工具链革命

**一句话总结**：_本周 GitHub 上多个机器人基础设施项目呈现爆发式增长——仿真平台 Genesis World（29588★）接近 3 万星，Rust 编写的机器人 OS Copper RS（1413★）持续迭代，Tensor 的 VLA 训练框架 OpenTau 正式开源。_

> 💡 **为什么重要**：如果说一年前的开源机器人运动是"做机器人"（硬件项目），那现在的阶段是**"造机器人的工具"**——仿真环境、操作系统、训练框架这些底层基础设施的开源化，正在系统性降低机器人研发的准入门槛。

**Genesis World（29,588★）**——通用机器人仿真平台

Genesis 是一款面向通用机器人学和具身 AI 学习的仿真平台。接近 3 万星意味着它已经成为机器人研究社区的事实标准之一。其核心价值在于：

- **GPU 加速物理仿真**：大规模并行训练机器人策略
- **多样化环境库**：从四足、双足到机械臂操作的完整场景覆盖
- **Sim-to-Real 迁移支持**：简化从仿真到真机的部署流程

**Copper RS（1,413★）**——用 Rust 写一个机器人操作系统

Copper 的口号直接而大胆："Copper is an operating system for robots——build, run, and replay your entire robot deterministically。"其核心卖点是**确定性回放**——机器人行为可以精确复现，这对调试和测试来说是革命性的。Rust 的内存安全特性使其在实时系统中具有天然优势。

**OpenTau（187★）**——Tensor 开源 VLA 训练基础设施

OpenTau 是 Tensor 团队发布的 VLA（Vision-Language-Action）模型训练基础设施，定位为"Real-World Robotics in PyTorch"。虽然规模尚小，但 VLA 方向本身正在成为具身智能的核心范式——它代表的是"让机器人理解语言和视觉指令并执行动作"这条路线的工程化基础设施。

> 📌 **共同主题**：这些项目指向一个清晰的趋势——**机器人开发正在经历类似 2010 年代深度学习框架（TensorFlow/PyTorch）的开源基础设施大爆发**。当仿真、OS、训练框架全部开源，机器人研究的门槛将迎来一次显著下降。

🔗 [GitHub: Genesis World](https://github.com/genesis-world) | [GitHub: Copper RS](https://github.com/copper-rs) | [GitHub: OpenTau](https://github.com/opentau)
